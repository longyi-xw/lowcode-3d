> 状态：设计已获用户批准（2026-06-02）。下一步 writing-plans。

## 1. 目标 / 成功标准

把 behavior 框架从「纯逐帧 tick」扩到「也支持事件驱动」，并补足内置 behavior 到 ≥3，兑现 v0.5「悬停高亮」交互目标。

成功标准：

1. ✅ behavior 框架支持事件驱动 behavior（install 拿到 camera/domElement/raycaster；handle.dispose 清理监听）。
2. ✅ **hover-highlight**：Play 模式下指针悬停节点 → emissive 高亮，移开 → 还原；Stop → 还原 + 移除监听。
3. ✅ **bob**：Play 模式下节点沿轴正弦浮动；Stop 还原 transform。
4. ✅ 内置 behavior ≥3（auto-rotate + hover-highlight + bob），UI 的 add-picker 都列出、可加/编辑/删、可撤销。
5. ✅ 导出代码（Vite / Standalone）内嵌 hover-highlight（事件）+ bob（ticker），外部可运行、交互一致。
6. ✅ lint / typecheck / test 全绿；视觉验证清单（§12）通过。

## 2. 背景 / 现状

- **框架（Stage A/B）**：`Behavior<TParams>`（`src/runtime/three/behaviors/types.ts`）= `definition`(BehaviorDefinition) + `install(object, params) → BehaviorHandle` + `tick(object, params, handle, dt)` + `emit(varName, params, ctx) → string`。`BehaviorHandle = { dispose?() }`。registry per-adapter（`createThreeBehaviorRegistry` 注册 AutoRotate）。
- **auto-rotate** 是**无状态 + 纯逐帧**：install 返回 `{}`，tick 直接 `object.rotation[axis] += ...`，emit push 一个 `tickers.push(dt => ...)` 块。
- **adapter**（`src/runtime/three/adapter.ts`）：`installBehaviors(nodeId, bindings)` 调 `b.install(object, parsed.params)`（**只给 object**）；`tickBehaviors(dt)` 逐帧调 `tick`；`uninstallBehaviors` 调 `handle.dispose`。adapter 持 `scene` / `camera` + raycaster（pickAt 用）；**domElement(canvas) 在 ThreeViewport，不在 adapter**。
- **ThreeViewport**：enterPlay 时对有 behaviors 的节点 `installBehaviors`，RAF loop 里 `playState==="play"` 才 `tickBehaviors(clock.getDelta())`，exitPlay `uninstallBehaviors`。canvas/OrbitControls/OutlinePass 都在 viewport 持有。
- **导出 codegen**（`scene-codegen.ts`）：`buildScene()` 返回 `{ scene, camera, templates, tickers }`；prolog 声明 `const tickers = []`。behavior 的 `emit` 块在 buildScene 作用域内执行，能引用 `tickers` + `varName`，**但拿不到 `renderer`/`domElement`/raycaster**（这些在 emitter main.js，buildScene 返回后才建）。
- **缺口**：roadmap 候选 hover/click/event-emit **全是事件驱动**（pointer + raycast）；现框架 install 不给运行上下文、导出端 emit 不给 renderer/domElement → 必须扩框架。

## 4. 框架扩展

`src/runtime/three/behaviors/types.ts`：

```ts
export interface BehaviorContext {
  scene: THREE.Scene;
  camera: THREE.Camera;
  /** null in non-viewport contexts (tests); event behaviors no-op when null. */
  domElement: HTMLElement | null;
  raycaster: THREE.Raycaster;
}

export interface BehaviorHandle {
  dispose?(): void;
}

export interface Behavior<
  TParams = unknown,
  THandle extends BehaviorHandle = BehaviorHandle,
> {
  readonly definition: BehaviorDefinition;
  install(object: THREE.Object3D, params: TParams, ctx: BehaviorContext): THandle;
  tick?(object: THREE.Object3D, params: TParams, handle: THandle, dt: number): void;
  emit(varName: string, params: TParams, ctx: CodegenContext): string;
}
```

`adapter.ts`：

- 加私有 `behaviorDomElement: HTMLElement | null = null` + `setBehaviorDomElement(el)` + 私有 `behaviorRaycaster = new THREE.Raycaster()`（或复用 pickAt 的）。
- `installBehaviors`：构造 `ctx = { scene, camera, domElement: behaviorDomElement!, raycaster }`，调 `b.install(object, parsed.data, ctx)`。若 domElement 未注入（导出/测试无 viewport），事件 behavior 的 install 应能优雅降级（无 domElement 就不装监听）——或 installBehaviors 在 domElement null 时给个 `document.createElement` 兜底；**决议：ctx.domElement 允许为 null 时跳过事件注册**（hover-highlight.install 内 guard）。把 `BehaviorContext.domElement` 设为 `HTMLElement | null`。
- `tickBehaviors`：`entry.behavior.tick?.(object, params, handle, dt)`。
- auto-rotate：install 签名加 `_ctx` 忽略；tick 保留。

ThreeViewport：mount effect 里 `adapter.setBehaviorDomElement(renderer.domElement)`。

## 5. hover-highlight（`src/runtime/three/behaviors/hover-highlight.ts`）

- 参数 `{ color: string(hex, 默认 "#ffaa00"), intensity: number(默认 1, ≥0) }`（zod schema）。
- handle 类型 `HoverHighlightHandle = { dispose(): void }`。
- install(object, params, ctx)：
  - 若 `ctx.domElement == null` → 返回 no-op handle（导出/测试降级）。
  - 收集 `object` 子树里 `mesh.material` 带 `emissive`（`THREE.Color`）的 mesh，记录原 emissive（clone）。
  - `onMove(e)`：算 NDC（用 ctx.domElement.getBoundingClientRect）→ `ctx.raycaster.setFromCamera(ndc, ctx.camera)` → `intersectObject(object, true)` → 命中则每个 mesh `material.emissive.set(color).multiplyScalar(intensity)`；未命中则还原。`onLeave`：还原。
  - 在 ctx.domElement 上 addEventListener('pointermove'/'pointerleave')。
  - handle.dispose：removeEventListener + 还原所有 emissive。
- emit(varName, params, ctx)：push 进 `interactions`（不是 tickers）：
  ```
  interactions.push((rt) => { /* rt = {renderer,camera,domElement,raycaster} */
    /* 同 install 的 pointermove + emissive 交换，针对 varName 子树 */
  });
  ```

## 6. bob（`src/runtime/three/behaviors/bob.ts`）

- 参数 `{ axis: "x"|"y"|"z", amplitude: number, frequency: number(Hz) }`。
- handle 类型 `BobHandle = { base: number; elapsed: number }`。
- install(object, \_params, \_ctx)：返回 `{ base: object.position[axis], elapsed: 0 }`。
- tick(object, params, handle, dt)：`handle.elapsed += dt; object.position[params.axis] = handle.base + params.amplitude * Math.sin(2*Math.PI*params.frequency*handle.elapsed)`。
- emit：push ticker（闭包存 base + 累积 t，同 auto-rotate 模式）。
- Stop 还原：依赖 ThreeViewport exitPlay 既有的「重新 sync 授权 transform」机制（与 auto-rotate 一致）；bob 不额外处理。
