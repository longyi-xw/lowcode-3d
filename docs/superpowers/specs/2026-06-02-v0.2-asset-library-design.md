# v0.2 资源库（asset library）设计

> 状态：设计已获用户批准（2026-06-02）。下一步 writing-plans。
> v0.2 拆分：**本 sub-stage = 资源库**（先做）；**材质编辑**是另一个 sub-stage（后做）。分支 `feat/v0.2-asset-library`（从 main，v0.1+v0.5 已合并）。

## 1. 目标 / 成功标准

一个底部资源库抽屉，分类罗列「可加进场景的东西」——内置几何基本体 / 灯光预设 / 用户上传的 .glb——**双击**即在场景创建对应节点（可撤销）。并让 mesh 支持几何变体（cube/sphere/plane/cylinder）。

成功标准：

1. ✅ 底部资源库抽屉，可经 `Cmd/Ctrl+J` 或头部按钮收缩/展开。
2. ✅ 抽屉按分类（几何 / 灯光 / 上传）罗列条目，可搜索（按名过滤）。
3. ✅ 双击库条目 → 在场景根创建对应节点并选中，**可撤销/重做**（AddNodeCommand）。
   - 几何 → mesh 节点（对应 `geometry.kind`）；灯光 → light 节点（预设）；上传 → prefab_instance（引用该 .glb asset）。
4. ✅ 「上传 .glb」入库：导入只把 AssetReference 加进 `project.assets`，资源出现在库的「上传」分类；save/open 后保留；可多次双击添加。
5. ✅ mesh 支持 box/sphere/plane/cylinder（编辑器视口 + 导出代码几何正确）；旧项目（mesh 仅 asset_id）向后兼容迁移为 box。
6. ✅ lint / typecheck / test 绿；视觉验证清单（§14）通过。

## 2. 背景 / 现状

- **MeshData**（`schemas.ts` NodeDataSchema mesh 变体）= `{ type:"mesh", asset_id: string, material_overrides?: MaterialOverride[] }`。**无 geometry 字段**——`mesh.ts` node-builder 写死 `BoxGeometry(1,1,1)`（line 22），`applyOverrides(material, material_overrides?.[0])` 已应用材质（line 30/38）。codegen `emitMesh`（`scene-codegen.ts:243-248`）写死 `BoxGeometry` + `MeshStandardMaterial({color:0xcccccc,metalness:0,roughness:0.7})`，**忽略 geometry + overrides**。
- **AssetReferenceSchema**：`kind: enum["geometry","texture","hdri","audio","video"]`；`source` 变体 `builtin{library_id}` / `user_upload{original_filename}` / `online` / `ai_generated`。`project.assets: AssetReference[]`。
- **importGlb**（`actions.ts`）：内容寻址导入 .glb → `addAsset(AssetReference)` + `addNode(prefab_instance)` + 选中 + markDirty（即「导入即加一个」）。File>Import 菜单 + StartupView import_glb 入口。
- **prefab_instance** node + builder：clone glb template（AssetCache）。
- **EditorView 布局**：CSS grid，左 `<aside>`(层级) · 中 `<main>`(ThreeViewport) · 右 `<aside>`(Properties|Behaviors tab, `NodeProperties` 用 `Vec3Row` 编 transform)。各项 `h-full min-h-0 overflow-hidden`。
- **useSceneStore**：`addNode` / `removeNodeSubtree` / `restoreNodeSubtree` / `addAsset` 等 mutator（subtree mutators 来自 3.1）。命令历史：`executeCommand`；3.1 有 DeleteNodeCommand/DuplicateNodeCommand（无通用 AddNodeCommand）。
- **useUIStore**：boolean+setter 模式（`helpOpen`/`newProjectOpen` 等）。`use-editor-shortcuts`（3.1）全局键盘 hook。

## 4. Schema（`schemas.ts` / `types.ts`）

- `GeometryDescriptorSchema = z.object({ kind: z.enum(["box","sphere","plane","cylinder"]) })`。
- MeshData 变体改为：
  ```ts
  z.object({
    type: z.literal("mesh"),
    geometry: GeometryDescriptorSchema.default({ kind: "box" }),
    asset_id: z.string().optional(),
    material_overrides: z.array(MaterialOverrideSchema).optional(),
  });
  ```
- **迁移**：`.default({kind:"box"})` 让旧 mesh（无 geometry）parse 即得 box——无需独立迁移代码，`deserializeProject`/`parseSceneProject` 自动兜底。
- 工厂更新：`createDemoProject`/`createSingleCubeProject` 的 cube mesh 改带 `geometry:{kind:"box"}`（asset_id 可留可去；为干净去掉 cube mesh 的 asset-cube 依赖——但 single-cube 防漂移测试需对应更新 examples/single-cube 或测试规则）。**决议**：保留 asset_id 兼容、加 geometry 字段；single-cube 工厂 + 防漂移测试同步加 geometry。

## 5. mesh node-builder（`node-builders/mesh.ts`）

- 按 `data.geometry.kind` 建几何（默认尺寸）：box=`BoxGeometry(1,1,1)`、sphere=`SphereGeometry(0.5,32,16)`、plane=`PlaneGeometry(1,1)`、cylinder=`CylinderGeometry(0.5,0.5,1,32)`。抽一个 `geometryFor(kind)` 纯函数。
- `applyOverrides` 保留不动。update 路径同样按 kind 重建（或 kind 不变时复用）。

## 6. codegen `emitMesh`（`scene-codegen.ts`）

- 按 `node.data.geometry.kind` emit 对应 `new THREE.XxxGeometry(...)`（同 §5 默认参数）。
- 材质保持现状默认 `MeshStandardMaterial({color:0xcccccc,metalness:0,roughness:0.7})`（**本期不读 material_overrides**）。
- 去掉「placeholder cube」warning（现在几何是真的按 kind 来的）；保留 mesh 无 asset 几何的说明若需要。

## 7. 库目录（`src/services/library/catalog.ts`）

- `LibraryItem = { id: string; category: "geometry"|"light"|"upload"; nameKey?: string; name?: string; icon: LucideIcon; makeNode: () => SceneNode }`。
- **内置（静态）**：
  - geometry：box/sphere/plane/cylinder → `makeNode` 建 mesh 节点 `{type:"mesh", geometry:{kind}, ...}`（fresh uuid、名如「Box」）。
  - light：directional/point/spot/ambient 预设 → `makeNode` 建 light 节点（默认 color/intensity，对齐现有 light data）。
- **用户上传（动态）**：从 `project.assets` 过滤 `source.kind==="user_upload"` → 每个 = 一个 upload item，`makeNode` 建 prefab_instance（asset_id）。`name` 用 `source.original_filename`。
- catalog 来源无关：内置是静态数组；上传从 store 派生；future online/ai 同样派生。

## 8. 库面板 UI（`src/ui/library/LibraryPanel.tsx`）

- **底部全宽抽屉**。EditorView 布局加底部一行（视口+左右面板之下，全宽）；展开时固定高度（如 ~180px），收起时只剩窄 bar（头部）。
- 头部：标题「资源库」+ 分类 tab（几何 / 灯光 / 上传）+ 搜索框 + 「上传 .glb」按钮 + chevron 收缩按钮。
- 内容：当前分类的横向滚动**卡片网格**（icon + 名）。双击卡片 → 加节点。
- 开关：`useUIStore.libraryOpen`（默认展开 or 收起？**默认收起**，按需展开）+ `setLibraryOpen`。`Cmd/Ctrl+J` 在 `use-editor-shortcuts` toggle（加进 shortcuts-registry 帮助列表）。chevron 按钮同样 toggle。

## 9. 加节点 = AddNodeCommand（`src/core/command/commands/add-node.ts`，新增）

- payload `{ node: SceneNode }`。apply：`store.addNode(node)`（加到场景根）+ 选中（或由 panel 选中）；revert：`store.removeNodeSubtree(node.id)`。复用 3.1 subtree mutators。canMergeWith=false。
- 双击库条目 → `item.makeNode()` → `executeCommand(new AddNodeCommand({node}))` → 选中。

## 10. 上传入库（`actions.ts`）

- 新增 `uploadGlbToLibrary()`：复用 importGlb 的内容寻址导入，但**只** `addAsset(AssetReference)` + markDirty，**不** addNode（资源出现在库的「上传」分类）。库的「上传 .glb」按钮调它。`exclusive("importGlb")` 守卫复用。
- 现有 `importGlb`（File>Import 菜单 / StartupView）**本期不动**（仍导入即加一个）；统一入口是后续清理。spec 注明。
