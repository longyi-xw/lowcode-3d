# Phase 3 · 3.2 项目模板系统 设计

> 状态：设计已获用户批准（2026-05-31）。下一步 writing-plans。
> 前置：3.1 快捷键完整化已合并（PR #23）。本 sub-stage 在 `feat/phase3-3.2-templates` 分支。

## 1. 目标 / 成功标准

让用户「New project」时能从一个统一的模板选择 Dialog 里挑起始场景，而不是无条件落入固定的 demo 场景。

成功标准：

1. ✅ 两个 New 入口（StartupView「New project」按钮 + 原生 File>New 菜单 ⌘N）都打开同一个模板选择 Dialog。
2. ✅ Dialog 列出 3 个模板：**起步场景 starter**（默认/推荐）、**单立方体 single-cube**、**空项目 empty**。
3. ✅ 点击任一模板卡 → 脏检查（dirty 时弹原生 confirm）→ 载入对应 SceneProject 进编辑器 → Dialog 关闭。
4. ✅ 每次新建都是 fresh project（新 `metadata.id` + 时间戳），不是 stale fixture。
5. ✅ 删除 StartupView 现有的占位「templates」section（three_vite / r3f_next）。
6. ✅ lint / typecheck / test 全绿；视觉验证清单（§11）通过。

## 2. 背景 / 现状

- `newProject()`（`src/services/project/actions.ts`）当前恒定 `exclusive("newProject") → confirmDiscard → loadProjectIntoEditor(createDemoProject(), null)`。
- `createDemoProject(name)`（`src/services/scene/demo-project.ts`）产 grid helper + Models 组(→cube) + key-light(directional) + fill-light(ambient)，runtime 0.184.0，slug 节点 id，fresh uuid。注释自陈「temporary until a real template picker lands」。
- `createDefaultProject(input)`（`src/core/scene/defaults.ts`）产最小空 SceneProject（nodes:{} / root:[] / bg `#0a0a0a`）。`examples/empty-project/project.json` 的内容正好等价于它的输出。
- `examples/{empty-project,single-cube}/project.json` 是 **docs/test fixture**（README 明示），被 `src/core/scene/parse.test.ts` 解析。固定 id（`…0001/…0002`）、固定时间戳、旧 runtime `0.164.0`、单文件 in-memory shape。**不能改它们的内容**否则 parse.test 挂。
- `single-cube` fixture = cube(mesh, asset-cube builtin) + key-light(directional) + main-camera(perspective)，bg `#101418`，3 个 root 节点，无 grid、无 ambient、无组。
- StartupView 已有「templates」section，但那是 `three_vite`（dev 助手 `open("editor")` 假载 demo）+ `r3f_next`（disabled, soon badge）—— 属**目标运行时框架**模板，与本 sub-stage 的「起始场景内容」是两条轴，存在术语撞车，本次撤掉占位 section 解决。
- `⌘N` 不是独立全局快捷键，是 File>New 原生菜单的 accelerator → 经 `useProjectMenu` 调 `newProject()`。故 New 实际只有两个入口、共用 `newProject()`。
- `useUIStore`（`src/services/ui/store.ts`）是 boolean+setter 模式（`helpOpen/setHelpOpen` 等）。
- `App.tsx` 是顶层 view switcher（startup/loading/editor/error），是覆盖所有 view 的 Dialog 挂载点。
- `loadProjectIntoEditor(project, path)` 同步完成 setProject + 清选择 + 清 command history + setCurrentPath + markClean + setView("editor") + Tauri setCurrentProjectPath。

## 4. 模板注册表 `src/services/scene/templates.ts`（新增）

```ts
import type { LucideIcon } from "lucide-react";
import type { SceneProject } from "@/core/scene/types";

export type TemplateId = "starter" | "single-cube" | "empty";

export interface ProjectTemplate {
  id: TemplateId;
  /** i18n key under "project" namespace. */
  nameKey: string;
  descriptionKey: string;
  icon: LucideIcon;
  recommended?: boolean;
  /** Always returns a fresh project (new metadata.id + timestamps). */
  create: (name?: string) => SceneProject;
}

export const PROJECT_TEMPLATES: ProjectTemplate[]; // 顺序: starter → single-cube → empty
```

- **starter** → 复用现有 `createDemoProject`（recommended: true）。
- **empty** → 包一层 `createDefaultProject({ id: generateUUID(), name, target: CURRENT_TARGET })`。
- **single-cube** → 新增 `createSingleCubeProject(name)`：忠实镜像 `examples/single-cube`——cube(mesh, asset-cube builtin geometry) + key-light(directional, #ffffff, 1.2, cast_shadow) + main-camera(perspective, fov 50/near .1/far 1000)，bg `#101418`，root 顺序 `["cube-1","key-light","main-camera"]`，**fresh uuid + 时间戳 + runtime 0.184.0**（对齐 demo，不沿用 example 旧的 0.164.0）。
- 三个工厂都建立在 `createDefaultProject` 之上以保证 schema 合法。`CURRENT_TARGET` 复用 demo-project 里的 `TARGET`（0.184.0）。
- 清理：删 `demo-project.ts` 里「temporary "New project" payload until a real template picker lands」那段注释（它现在正式是 starter 模板）。

## 5. 状态 + actions 重构

**`src/services/ui/store.ts`**（照 `helpOpen` 模式）：

```ts
newProjectOpen: boolean;            // default false
setNewProjectOpen: (open: boolean) => void;
```

**`src/services/project/actions.ts`**：

- `newProject()` 改为只开 picker（非破坏性）：
  ```ts
  export function newProject(): void {
    useUIStore.getState().setNewProjectOpen(true);
  }
  ```
  去掉 exclusive / confirmDiscard / 直接 load（破坏性动作下移到 createProjectFromTemplate）。调用处 `void newProject()` 仍兼容。
- 新增：
  ```ts
  export async function createProjectFromTemplate(id: TemplateId): Promise<void> {
    await exclusive("newProject", async () => {
      const tpl = PROJECT_TEMPLATES.find((t) => t.id === id);
      if (!tpl) return;
      if (!(await confirmDiscard("Start a new project and discard current changes?")))
        return;
      loadProjectIntoEditor(tpl.create(), null);
      useUIStore.getState().setNewProjectOpen(false);
    });
  }
  ```

  - 取消 discard → 直接 return，picker 保持开（用户可再选或关）。
  - clean（首次启动 / 非脏）时 confirmDiscard 立即返 true，无原生弹窗，秒建。
  - `loadProjectIntoEditor` 的形参类型从 `ReturnType<typeof createDemoProject>` 放宽到 `SceneProject`（已等价，仅命名收敛）。
- File>New 菜单（`useProjectMenu`）**不改** —— 仍调 `newProject()`，行为已变成开 picker。
