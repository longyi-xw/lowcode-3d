---

## 1. 背景与目标

B3b smoke 发现：Babylon 模式下改材质属性（颜色/金属度/…）**实体不变**。根因——`BabylonAdapter` 从没实现材质：`createMesh` 建几何不设 material，`syncNode("update")` 只做 transform+visible。Three 在 `node-builders/mesh.ts` 用共享 `resolveMaterial` + Three 专有 apply 应用到 `MeshStandardMaterial`。

**B4a 目标**：Babylon mesh 应用 PBR 材质覆盖（color/metalness/roughness/emissive/emissive_intensity/opacity，slot 0），create + update 都生效，与 Three 跨引擎对等。

### 已与用户确认的决策

- **材质类 = `PBRMaterial`**：6 字段全 1:1 映射（含 `emissiveIntensity`），PBR 语义对齐 Three 的 `MeshStandardMaterial`。否决：`PBRMetallicRoughnessMaterial`（缺 emissiveIntensity 要预乘）、`StandardMaterial`（Phong，metalness/roughness 不映射，偏离 PBR）。代价：金属在无 IBL 环境贴图时偏暗——观感对齐属 **B4d**，本期保证字段值正确（color/emissive/opacity 立即可见）。
- **含 conformance 材质对等**：`RuntimeNodeInfo` 加 `material?` + 两引擎 `describeNode` 读真实材质 + conformance 断言两引擎对同一覆盖报等价材质（仿 B2 拾取对等，给跨引擎材质保证）。

## 3. 复用 + 新增

- **复用不动** `resolveMaterial(override?): ResolvedMaterial`（`@/core/scene/material`）：default ⊕ override → `{color, metalness, roughness, emissive, emissive_intensity, opacity}`，`DEFAULT_MESH_MATERIAL.color="#cccccc"`。Three/Babylon 共用。
- **新** `src/runtime/babylon/material.ts`：

```ts
import { Color3, PBRMaterial, type Scene } from "@babylonjs/core";
import type { ResolvedMaterial } from "@/core/scene/material";

/** Full-set a Babylon PBRMaterial from a resolved (default ⊕ override)
 *  descriptor. Sets every field unconditionally so clearing an override resets
 *  to default (mirrors three/node-builders/mesh.applyResolvedMaterial). */
export function applyPbrMaterial(mat: PBRMaterial, m: ResolvedMaterial): void {
  mat.albedoColor = Color3.FromHexString(m.color);
  mat.metallic = m.metalness;
  mat.roughness = m.roughness;
  mat.emissiveColor = Color3.FromHexString(m.emissive);
  mat.emissiveIntensity = m.emissive_intensity;
  mat.alpha = m.opacity;
  mat.transparencyMode =
    m.opacity < 1 ? PBRMaterial.MATERIAL_ALPHABLEND : PBRMaterial.MATERIAL_OPAQUE;
}

export function createPbrMaterial(name: string, scene: Scene): PBRMaterial {
  return new PBRMaterial(`${name}-mat`, scene);
}
```

### 字段映射（ResolvedMaterial → PBRMaterial）

| Resolved             | PBRMaterial                                                                     |
| -------------------- | ------------------------------------------------------------------------------- |
| `color`(hex)         | `albedoColor = Color3.FromHexString(color)`                                     |
| `metalness`          | `metallic`                                                                      |
| `roughness`          | `roughness`                                                                     |
| `emissive`(hex)      | `emissiveColor = Color3.FromHexString(emissive)`                                |
| `emissive_intensity` | `emissiveIntensity`                                                             |
| `opacity`            | `alpha`；`transparencyMode = opacity<1 ? MATERIAL_ALPHABLEND : MATERIAL_OPAQUE` |

## 4. 接线（`src/runtime/babylon/adapter.ts`）

- `createMesh`（约 :335）：签名加 `materialOverride?: MaterialOverride` 参数（与 Three `build()` 内聚一致），建 mesh 后应用材质；`create()` 调用处传 `data.material_overrides?.[0]`：

```ts
const mat = createPbrMaterial(name, scene);
applyPbrMaterial(mat, resolveMaterial(materialOverride));
mesh.material = mat;
```

- `syncNode("update")`（约 :116-128，现仅 transform+visible）：mesh 节点重应用材质。加 guard——只对「existing 是 `Mesh` 且 `material instanceof PBRMaterial`」：

```ts
if (existing instanceof Mesh && existing.material instanceof PBRMaterial) {
  applyPbrMaterial(
    existing.material,
    resolveMaterial(node.data.material_overrides?.[0]),
  );
}
```

（`node.data` 是 mesh 时才有 material_overrides；`requireMeshData` 式守卫或 `node.data.type === "mesh"` 判断。）

## 5. RuntimeNodeInfo.material + describeNode + conformance

- `src/runtime/adapter.ts`：`RuntimeNodeInfo` 加：

```ts
export interface MaterialInfo {
  color: string; // hex #rrggbb
  metalness: number;
  roughness: number;
  emissive: string; // hex
  emissive_intensity: number;
  opacity: number;
}
// RuntimeNodeInfo:
material?: MaterialInfo; // mesh 节点才有
```

- `ThreeAdapter.describeNode`：mesh 时读 `MeshStandardMaterial` → `{color: '#'+mat.color.getHexString(), metalness, roughness, emissive: '#'+mat.emissive.getHexString(), emissive_intensity: mat.emissiveIntensity, opacity: mat.opacity}`。
- `BabylonAdapter.describeNode`：mesh 时读 `PBRMaterial` → `{color: mat.albedoColor.toHexString(), metallic, roughness, emissive: mat.emissiveColor.toHexString(), emissive_intensity: mat.emissiveIntensity, opacity: mat.alpha}`。
- conformance（`conformance-suite.ts`）：对带 material_overrides 的 mesh 节点，断言两引擎 `describeNode().material` 等价（color/emissive 比 hex 字符串——两引擎都报原始 sRGB hex，gamma 差在渲染内部不影响 hex；数值字段 `toBeCloseTo`）。

> **hex 对等成立的理由**：Three `color.getHexString()` 把内部 linear 转回 sRGB = 原 hex；Babylon `albedoColor.toHexString()` = `FromHexString` 存的原值 = 原 hex。两侧描述符层都报原 hex；真实渲染的 gamma/linear 差异属 B4d，不影响 describeNode 对等。

## 7. 风险

- **色彩空间（B4d）**：`Color3.FromHexString` 取 sRGB 原值当 linear 用，Three `color.set` 走 sRGB→linear；颜色会显示但与 Three 渲染可能有 gamma 差。describeNode 层报原 hex 故对等成立；观感精确对齐留 B4d。
- **金属无 IBL 偏暗（B4d）**：metallic 高的材质 Babylon 无环境贴图时暗。本期 color/emissive/opacity 立即可见，metallic 值正确观感待 B4d。
- **update guard**：syncNode update 现对所有 kind 跑；材质重应用须 guard 只对 mesh+PBRMaterial（light/camera/group 节点不碰）。
- **prefab/glTF mesh**：本期只覆盖 builder 建的几何 mesh（box/sphere/…）；glTF 导入 mesh 的材质属 A3/后续，update guard 的 `material instanceof PBRMaterial` 天然跳过非 PBR 的导入材质。
