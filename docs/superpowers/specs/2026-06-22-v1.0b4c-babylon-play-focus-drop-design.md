## 1. 背景与目标

B3b 让 Babylon 模式可拖动+吸附，但 `engineCapabilities` 仍把 **play / focus / assetDrop** 门为 three-only——Babylon 模式 Play 按钮/F/资源拖入禁用或无效。Three 这三项在 ThreeViewport 用引擎专有面（`setFrameCallback`/`focusCamera`）+ adapter（`raycastGroundPoint`）+ 引擎中立 helper（`computeFocusTarget`/`drop-helpers`/`installBehaviors`）实现。

**B4c 目标**：把 play 行为预览、F focus、资源拖放落点接到 BabylonViewport，翻 `engineCapabilities` 三 flag → Babylon 模式与 Three 全对齐可编辑。

### 已与用户确认的决策

- **一个 sub-stage**（play+focus+drop 一起）：三者都小、共享「加 host/adapter 引擎专有面 + BabylonViewport 接线 + 翻 flag」同模式、都镜像 ThreeViewport 成熟实现，风险低。
- **`raycastGroundPoint` 提到 `IRuntimeAdapter` + conformance 对等**：从 ThreeAdapter 专有方法升为契约方法，两引擎实现，conformance 断言两引擎对同屏幕点报等价地面命中（仿 B2 pick parity，复用 `makePickAdapter` 定尺寸视口）。
- **保留 `engineCapabilities` seam**：翻完三 flag 后四项两引擎全 true（vestigial-but-kept）；不删函数——v1.x 新引擎（r3f/Unity）可能不全支持，留作能力门扩展点。

## 3. BabylonRenderHost 引擎专有面（镜像 ThreeRenderHost）

- `setFrameCallback(cb: ((dt: number) => void) | null)`：存 `this.frameCb`；在 `start()` 的 `runRenderLoop` 回调里 `scene.render()` 前调 `this.frameCb?.(engine.getDeltaTime() / 1000)`（`getDeltaTime()` 是毫秒 → 秒，对齐 Three Clock delta；`tickBehaviors` 期望秒）。
- `focusCamera(target: Vector3, distance: number)`：`camera.setTarget(target); camera.radius = distance`（ArcRotateCamera 保持当前 alpha/beta，把目标居中、退到 distance）。
- `dispose()` 清 `frameCb`。

> `Vector3` 是引擎类型，但 `focusCamera` 是 ThreeRenderHost 已有先例的引擎专有面（Three 版收 `THREE.Vector3`）；Babylon 版收 `Vector3`（@babylonjs/core）。viewport 的 focus effect 用 `computeFocusTarget`（引擎中立返回 `{target,distance}`）——但 target 是各引擎的 Vector3。**注意**：`computeFocusTarget`（`./focus-helpers`）当前签名收 Three Object3D / 返回 THREE.Vector3。Babylon 需要等价计算——见 §6 决策。

## 4. IRuntimeAdapter.raycastGroundPoint + Babylon 实现 + conformance

- `src/runtime/adapter.ts`：`IRuntimeAdapter` 加 `raycastGroundPoint(screen_x: number, screen_y: number): [number, number, number] | null;`（ThreeAdapter 已实现，签名一致，只是升到契约）。
- `BabylonAdapter.raycastGroundPoint`：用 `this.scene.activeCamera`（pickAt 同款——headless 是默认 editor UniversalCamera、mount 后是 render host 的 ArcRotateCamera）。`scene.createPickingRay(screen_x, screen_y, Matrix.IdentityReadOnly, this.scene.activeCamera)` → `ray.intersectsPlane(Plane.FromPositionAndNormal(Vector3.Zero(), Vector3.Up()))`（或 `new Plane(0,1,0,0)`）得距离 `t`；`t == null || t < 0` → null；否则 `ray.origin.add(ray.direction.scale(t))` → `[x,y,z]`。视口尺寸 Babylon 从 engine 读，pickAt 同款。
- conformance（`conformance-suite.ts` 的 `makePickAdapter` 块，仿 pick parity）：定尺寸视口 + 默认编辑器相机，断言 `raycastGroundPoint(中心)` 两引擎得等价地面点（`toBeCloseTo`），`raycastGroundPoint(朝天角)` 两引擎都 null。

## 6. BabylonViewport 接线（镜像 ThreeViewport）

mount effect 内 + 一个 focus effect：

- **play**：订阅 `useUIStore.playState`→ enterPlay/exitPlay。
  - `enterPlay`：遍历节点 `transformSnapshots.set(id, captureTransform(adapter.getRuntimeObject(id)))`（`babylon/transform-util.captureTransform`，B3b 已有）+ `node.behaviors.length>0 → adapter.installBehaviors(id, behaviors)`；`host.setGizmoTarget(null,false)` + `host.setSelection(null)`；`playing=true`。
  - 帧 tick：`host.setFrameCallback((dt)=>{ if(playing) adapter.tickBehaviors(dt) })`。
  - `exitPlay`：`adapter.uninstallBehaviors(id)` 全节点 + 从快照恢复 position/rotationQuaternion/scaling + `transformSnapshots.clear()` + `playing=false` + 恢复选中（syncSelection/syncGizmoTarget）。
- **focus**：focus effect 订阅 `pendingFocusNodeId`→ 取 Babylon node → 算 `{target, distance}` → `host.focusCamera(target, distance)` → `consumeFocusRequest()`。**`computeFocusTarget` 决策**：现有 `focus-helpers.computeFocusTarget` 是 Three 专有（收 Object3D，用 Box3）。Babylon 需等价。决定：写 Babylon 侧 focus 目标计算（取 node `getHierarchyBoundingVectors` 算包围盒中心+尺寸→distance），放 BabylonViewport 或 `babylon/focus-helpers.ts`；**不强迁 computeFocusTarget 为引擎中立**（Box3/包围盒 API 引擎专有，强抽象收益低）——各引擎一份 focus 目标计算，host.focusCamera 收 target+distance 仍是共享接口形状。
- **drop**：`onAssetDrop`（window pointerup）→ `assetDragItemId` → `adapter.raycastGroundPoint(x,y)` → `dropPositionFor`（`@/lib/drop-helpers` 引擎中立）→ `findLibraryItem` → `AddNodeCommand` → `setSelectedNodeId`。逐字镜像 ThreeViewport :213-235。

## 8. 风险

- play delta 单位 ms→秒（/1000），错了行为速度差 1000×。
- focus：ArcRotateCamera setTarget/radius 与 Three「沿视线退」语义略不同（视觉等价，都居中到合适距离）；smoke 确认观感可接受。
- `raycastGroundPoint` 升契约：ThreeAdapter 签名已一致，但确认其 `viewportWidth/Height` 初始化路径（pickAt 同款）在 conformance 定尺寸下成立。
- enterPlay 遍历 `getRuntimeObject` 对非 mesh（light/camera/group）captureTransform——Babylon captureTransform 已防御读 position/rotationQuaternion/scaling（B3b），non-transform node 兜底；恢复同理。
- `engineCapabilities` 全 true 后 `void engine` 避免 unused-param lint；保留函数是有意（注释说明 seam）。
