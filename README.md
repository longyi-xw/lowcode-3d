# lowcode-3d

> AI-assisted low-code platform for the Web 3D stack. Visually arrange a scene, export production-ready Three.js code.

**Status**: pre-MVP scaffolding · `v0.0.1-scaffold`

## Stack

Tauri 2.x · React 18 · TypeScript · Three.js · Zustand · Tailwind CSS · shadcn/ui · react-i18next · SQLite

## Development

```bash
pnpm install
pnpm tauri dev
```

Requires Node 20 (see `.nvmrc`) and a Rust toolchain.
